# קורות חיים בצבעי החברה

## העלאה לאוויר
1. פותחים את הכתובת:
   https://app.netlify.com/drop
2. גוררים לשם את כל התיקייה הזו
3. מקבלים כתובת חיה
4. לדומיין משלך:
   Site settings → Domain management → Add a domain

## התראות לטלפון
1. מתקינים את האפליקציה
   ntfy
2. נרשמים לנושא:
   bar-cv-3bycxcb6u8e9
3. פותחים את האתר פעם אחת מהדפדפן שלך עם הסיומת:
   ?owner=1
   כך הכניסות שלך לא שולחות התראות. מכל דפדפן ומכשיר שלך בנפרד.

## עריכה
- פרטים אישיים, טקסט קורות החיים ורשימת החברות:
  data.js
- קישור לינקדאין: השדה
  CONFIG.linkedin
- אם מחברים דומיין משלך, מעדכנים את כתובת תמונת התצוגה בקובץ
  build.py
- שינויי עיצוב או קוד נעשים בתיקייה
  src
  ואחריהם מריצים:
  python3 build.py
